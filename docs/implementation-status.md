Diperbarui untuk memverifikasi `CartBadge` aktif dan trigger tunggal `CHAT_COPY.TRIGGER_OPEN`.
  4. **Perbaikan Hydration Race `useBranches` Lintas Suspense (`src/hooks/use-branches.ts`):** Saat menjalankan E2E produksi penuh pada `tests/e2e/site.spec.ts` dengan DB offline (`initial.status === 'error'`) dan respons cepat `/api/branches`, terdeteksi React hydration error `#418` di `HomeView`/`FindUsSection` karena sibling Suspense (`SiteHeader`) menyelesaikan query cabang sebelum child selesai hidrasi. Diperbaiki di akar (`useBranches`) dengan menahan eksposur data client query (`items`, `selected`, `isPending`, `isError`, `isEmpty`, `invalidUrl`) hingga `context.hydrated || hasServerInitial`.
  5. **Rekonsiliasi Status Dokumentasi (`docs/implementation-status.md`):** Menyelaraskan baris ringkasan `F15–F19` & `R06/R13/R15–R19` yang sebelumnya tertinggal sebagai `TODO`/`IN PROGRESS`, melampirkan matriks traceability penuh, dan menerbitkan [uat-f25.md](uat-f25.md) + `D032` di [decisions.md](decisions.md).
